## Summary

CWE-78 is OS command injection. Admin export jobs that pass filenames through a shell are the pattern. Keep exploit syntax out of remediation text; record that the shell was removed.

## Prevention

When a record cites CWE-78, retrieve this note for the definition and then verify the live status in SQLite. The CWE page does not know whether this company's incident is open.
