## Summary

CWE-494 is download of code without an integrity check. An admin artifact that does not match the signed manifest belongs here even when the pipeline kept only one log line.

## Prevention

When a record cites CWE-494, retrieve this note for the definition and then verify the live status in SQLite. The CWE page does not know whether this company's incident is open.
